# Creative Idea Generator

שלב שני במטלה בקורס סוכני AI: מחברת Python שמציעה בדיוק שלושה שימושים יצירתיים, יוצאי דופן ומעשיים לכל חפץ יומיומי. המחברת משתמשת ב־OpenAI Responses API ובמודל `gpt-6-luna` ומציגה את הרעיונות בעברית ברשימה ממוספרת (1, 2, 3).

## הרצה ב־Google Colab

1. פתחו את [Google Colab](https://colab.research.google.com/) והעלו את `creative_ideas.ipynb` מהמחשב.
2. הריצו את תא התקנת `openai` ולאחריו את תא התוכנית.
3. הזינו מפתח OpenAI API בשדה המוסתר של `getpass()` — פעם אחת לכל הרצת התוכנית.
4. הזינו שם חפץ יומיומי באמצעות `input()` וקבלו שלושה רעיונות.
5. בשאלה אם להמשיך, הזינו `כן` לחפץ נוסף ללא הפעלה מחדש, או `לא` לסיום עם הודעת פרידה. נתמכים גם `yes`/`no` ו־`y`/`n`.

קלט חפץ ריק אינו נשלח ל־API; התוכנית מבקשת חפץ שוב. תשובה ריקה או לא מוכרת לשאלת ההמשך גורמת לחזרה על השאלה. מפתח ריק מסיים את התוכנית. שגיאת אימות מסיימת עם הסבר; לאחר שגיאות מכסה, חיבור, API או תשובה לא תקינה אפשר לבחור אם לנסות חפץ נוסף.

התשובה מבוקשת כ־JSON עם בדיוק שלושה רעיונות, נבדקת לפני הצגתה וממוספרת בקוד. תשובה חלקית או סירוב אינם מוצגים כרשימת רעיונות.

נדרשים אינטרנט, מפתח API פעיל, גישה למודל ומכסת שימוש מתאימה. שימוש ב־API עשוי להיות כרוך בתשלום, וכל חפץ שנשלח יוצר בקשה נוספת.
