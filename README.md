# Creative Idea Generator

גרסה ראשונה למטלה בקורס סוכני AI: מחברת Python שמקבלת חפץ יומיומי ומציעה שימוש אחד בלבד, יצירתי, יוצא דופן ומעשי, בעברית. המחברת משתמשת ב־OpenAI Responses API ובמודל `gpt-6-luna`, ללא לולאה להזנת חפצים נוספים.

## הרצה ב־Google Colab

1. פתחו את [Google Colab](https://colab.research.google.com/) ובחרו פתיחת מחברת והעלאת הקובץ `creative_ideas.ipynb` מהמחשב.
2. הריצו את תא ההתקנה של `openai` ולאחריו את תא התוכנית.
3. הזינו שם חפץ יומיומי באמצעות `input()`.
4. הזינו מפתח OpenAI API בשדה המוסתר של `getpass()` וקבלו רעיון אחד.

נדרשים אינטרנט, מפתח API פעיל, גישה למודל ומכסת שימוש מתאימה. שימוש ב־API עשוי להיות כרוך בתשלום. המחברת מטפלת באופן בסיסי בשגיאות אימות, מכסה, חיבור ו־API.

## שמירת המפתח

אין לכתוב את המפתח בקוד, בקובץ, בתא טקסט או ב־GitHub. הוא מוזן בזמן הריצה בלבד, אינו מודפס ואינו נכתב לקובץ. המחברת נמסרת ללא פלטים שמורים. הודעות השגיאה אינן מציגות את פרטי החריגה. בסיום העבודה אפשר לנתק ולמחוק את סביבת הריצה ב־Colab כדי לשחרר את הזיכרון.
